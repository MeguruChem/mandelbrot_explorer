# Mandelbrot Explorer

ブラウザだけで動く、マンデルブロ集合とその仲間のビューアです。ビルド不要で、HTML ファイルを開けばそのまま動きます。

| ページ | 内容 |
|---|---|
| [`mandelbrot/`](mandelbrot/index.html) | 2次元のマンデルブロ集合／ジュリア集合のディープズームビューア |
| [`mandelbulb/`](mandelbulb/index.html) | 3次元のマンデルバルブ／ジュリアバルブのビューア（WebGL） |

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチのルートを指定すると、`index.html` から両方のページに行けます。

## マンデルブロ・エクスプローラー（`mandelbrot/`）

### できること
- ドラッグで移動、ホイール／ピンチで拡大縮小、ダブルクリックで3倍に拡大
- **自動ズーム**：中心へまっすぐ／発散が最も遅い点を追う／ランダムツアー（乱数で出発し、画素値の差が大きい点を追い続ける）
- **有名な点へダイブ**：ミシュレヴィッチ点（c = i、三叉の分岐点、渦の中心など）、ファイゲンバウム点、深いミニブロ（周期 998、周期 2288・約 10⁸⁰ 倍）。座標は mpmath で約 90 桁まで求めた値
- 一時停止・再開（画面に触れると一時停止し、再開すると元の目的地へ戻って続きを潜る）
- 座標の書き出し・読み込み（数十〜数百桁）
- **ジュリア集合モード**：今の画面中心の c でジュリア集合を描く（double 精度、約 10¹³ 倍まで）

### 計算の仕組み
| 段階 | 内容 |
|---|---|
| エスケープタイム法 | z ← z² + c を反復し、発散までの回数をなめらかな値（smooth coloring）にして色を付ける |
| 多倍長の参照軌道 | 画面内の 1 点の軌道だけを BigInt の固定小数点で計算（専用の Web Worker） |
| 摂動論 | 各ピクセルは参照軌道との差 ε だけを double で計算。参照軌道の乗り換え（rebasing）とグリッチの再計算付き。約 10²⁹⁰ 倍まで |
| BLA（双線形近似） | 2ᵏ 回分の反復を 1 次式にまとめた表で、誤差が小さいうちは一気に飛ばす |
| WebAssembly + SIMD | 反復ループを AssemblyScript で書き、128bit SIMD で隣り合う 2 ピクセルを同時に計算。非対応ブラウザでは自動で通常版／JavaScript 版を使う |
| 補間 | 4 ピクセルおきの格子点だけ計算し、距離推定の円がマスを覆う所は、ポテンシャル（集合の外で調和関数）上で補間 |
| 速度の自動調整 | 描画時間からズーム速度をなめらかに決め、描画が追いつかなくても止まらないようにする |

「計算」タブで、WebAssembly・SIMD・BLA・内側判定・double のみ、を個別に切り替えて比べられます。

### wasm のビルド
`mandelbrot/index.html` には、ビルド済みの wasm が base64 で埋め込まれています。`wasm/mandel.ts` を変更したときだけ、次で作り直して埋め込み直します。

```bash
npm install
```

```bash
npm run build:wasm
```

SIMD 版と、SIMD の部分を除いた通常版の 2 つを作り、それぞれ `WASM_SIMD_B64` と `WASM_B64` に埋め込みます。

## マンデルバルブ（`mandelbulb/`）
- 点を球座標で表し「長さを n 乗、角度を n 倍」して zⁿ の代わりにする White–Nylander の式（次数 n は 2〜16）
- 距離推定によるレイマーチング、ソフトシャドウ、環境光遮蔽
- ジュリアバルブ（c を固定）、次数や c をゆっくり動かすアニメーション
- トラックボール式のカメラ（どの向きでも回転できる）、ダブルクリックでその点へ近づく
- GPU の float 精度のため、近づけるのは数千倍程度まで
